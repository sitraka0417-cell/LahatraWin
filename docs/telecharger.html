Lahatra

Gestion de tâches pour Windows, synchronisée avec votre compte Google.

⬇ Télécharger pour Windows
Windows 10 et 11 (64 bits)

Installation

  1. Téléchargez puis lancez Lahatra-Setup.exe.
  2. Suivez l'assistant (choix du dossier, raccourcis).
  3. Ouvrez Lahatra et connectez-vous avec Google : vos tâches se synchronisent avec votre téléphone.

Mise à jour

  1. Relancez simplement le nouvel installateur : vos réglages et votre connexion sont conservés.
Message de Windows ? Si « Windows a protégé votre ordinateur » apparaît, cliquez sur Informations complémentaires, puis Exécuter quand même. L'application n'est pas encore signée numériquement.
